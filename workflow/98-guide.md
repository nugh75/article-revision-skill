# 98 — Recommended Revision Guide

Triggered by `/r-guide`. Standalone and read-only: no setup writes, bump, task,
sync, commit, or push.

```text
# Percorso consigliato

1. Wayfinder, se sono in gioco definizioni o confini tra costrutti.
2. /r-global o /r-audit per la diagnosi complessiva, ancora in sola lettura.
3. /r-redundancy se il problema è la ripetizione di idee o la circolarità.
4. Scrittura + tone-of-voice per formulare una proposta coerente.
5. /r-pp-a o /r-chapter per decisioni puntuali nel contesto del manoscritto.
6. Alla prima modifica accettata: nuova versione, task e ledger; poi applicazione.
7. /r-handoff per sospendere localmente; /r-handoff --git solo per pubblicare.
8. Chiusura locale con decision log e sync; commit/push richiesti separatamente.
9. /r-pr-2 come QA simulata; eventuale mini-round finale.

Sequenza breve:
Wayfinder → audit globale → ridondanza se necessaria → scrittura + ToV → applicazione tracciata → chiusura locale → Git opzionale
```

Then ask whether the user wants a read-only diagnosis or to start a tracked edit.
